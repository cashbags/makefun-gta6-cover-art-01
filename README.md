A web app that turns your photo and a caption into cover art in the style of GTA 6 posters — the multi-panel poster look, bold lettering and a Vice City sunset or neon colour grade — and exports it as a PNG to share. It runs offline in a desktop browser from its own static files; photos never leave your machine.

Pick a photo for each of three panels (or one photo for all three), drag to position it, scroll to zoom, write the title and subtitle, pick a layout (Trio, Hero, Solo) and a grade (Sunset, Neon Nights, Palm Gold, Mono), then export in 1080×1080, 1080×1350 or 1920×1080. Everything in it is original — no Rockstar logo, artwork or fonts.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
